# Тексеру нәтижесі

Тексерілген күні: 2026 жылғы 4 қазан.

Барлық 19 тапсырма орындалған. 18 автотест сәтті өтті.
Бір тест №14 және №15 тапсырмаларын бірге тексереді, сондықтан тест саны 18.
Тексеру ортасы: Windows x64, Python 3.10.19, PySpark 3.4.0,
pytest 7.4.0, Java 11.0.32.1.

## Не тексерілді

- SparkSession атауы және CSV-дегі 9 980 жол.
- Қолмен берілген схема және барлық баған түрлері.
- Бос сала, NULL сала және NULL есім жолдарын жою.
- Барлық gender кодтары, белгісіз код және NULL.
- Popularity шекаралары: 40, 39.999, 20, 19.999, 10, 9.999.
- Есімнің бос орындары мен әріп регистрі.
- SQL салалар статистикасы тәуелсіз CSV есебімен салыстырылды.
- Жыныс үлесі, әр саладан ең көбі 5 адам және popularity реті.
- Repartition/coalesce кейінгі бөліктер саны және жол санының сақталуы.
- Parquet жазу/оқу, сала қалталары және тек Acting жолдарын оқу.
- 1 және 8 партициямен нақты файлға жазу уақытын өлшеу.
- Pivot ұяшықтарындағы сандар және рейтингтегі тең popularity мәндері.
- Толық pipeline, шығыс бағандары және жазылған деректердің жол саны.

## Іске қосу нәтижелері

`pipeline.txt` файлында толық жобаны іске қосудың шығысы сақталған.
`../output/people/` қалтасында сала бойынша бөлінген дайын Parquet деректері бар.

GitHub Actions конфигурациясы дайын, бірақ GitHub репозиторийіне жүктеу
және сыртқы CI іске қосылуы осы жергілікті тексеруге кірмейді.

## Жергілікті орта

Тексеру үшін пайдаланылған Python, Java және Windows Hadoop көмекші файлдары
жоба жанындағы `work/pyspark-runtime` қалтасында орналасқан. Олар ZIP-ке кірмейді.
Java архивінің SHA256 сомасы жеткізушінің сомасымен салыстырылды.

Көздер: [Temurin Java 11](https://github.com/adoptium/temurin11-binaries),
[Windows Hadoop файлдары](https://github.com/cdarlint/winutils/tree/master/hadoop-3.3.5/bin),
[Spark 3.4.0 анықтамасы](https://archive.apache.org/dist/spark/docs/3.4.0/api/python/).
